## 📖 Concepts Learned

### Inversion Counting
- Understood what an inversion is:
  `i < j` and `nums[i] > nums[j]`
- Implemented the brute-force approach using nested loops.
- Used `long long` to safely store the inversion count.
- Learned that the optimal approach uses Merge Sort and can reduce the complexity to `O(n log n)`.

### Array Traversal
- Practiced traversing two logical halves of an array.
- Used indexed access to interleave corresponding elements.
- Built the required result using a separate vector.

---

## 💡 Key Takeaways

- A brute-force solution is useful for understanding the problem before learning the optimal approach.
- The number of inversions can become large, so `long long` is important.
- Count Inversions will be revisited after learning Merge Sort to implement the optimal solution.
