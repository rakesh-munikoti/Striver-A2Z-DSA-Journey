## 📖 Concepts Learned

### Bubble Sort
- Compared adjacent elements and swapped them when they were in the wrong order.
- Understood how the largest unsorted element moves toward the end after each pass.
- Time Complexity: O(n²)
- Space Complexity: O(1)

### Selection Sort
- Divided the array into sorted and unsorted portions.
- Found the minimum element from the unsorted portion.
- Placed the minimum element at its correct position.
- Time Complexity: O(n²)
- Space Complexity: O(1)

### Insertion Sort
- Maintained a sorted portion of the array.
- Took the current element and moved it toward its correct position using adjacent swaps.
- Understood why Insertion Sort performs well on already sorted or nearly sorted arrays.
- Best Case: O(n)
- Average/Worst Case: O(n²)
- Space Complexity: O(1)

### Product of Array Except Self
- Understood the connection between Prefix Sum and Prefix/Suffix Product.
- Built left-product information using the output array.
- Used a running right product during the reverse traversal.
- Solved the problem without using division.
- Handled zero values naturally.
- Time Complexity: O(n)
- Extra Space: O(1), excluding the output array.
