## 💡 Key Takeaways

Merge Sort follows:

`Divide → Sort → Merge`

The main idea is to:
1. Divide the array into two halves.
2. Recursively sort both halves.
3. Merge the two sorted halves.

This gives Merge Sort its efficient `O(n log n)` time complexity.

---

## ⏱️ Complexity

- Time Complexity: O(n log n)
- Auxiliary Space: O(n)
- Recursion Stack: O(log n)
